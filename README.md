A falling block puzzle game with a rainbow of revolving blocks.

===Building===
* For MAC/Linux depends on SDL2, SDL2 Image, and SDL2 gfx.
* Dreamcast depends on KOS. Platform not maintained.

===Controls===
* 12345 revolve a block clockwise according to its rainbow color if blob remains contiguous and there is no collision.
QWERT revolve a block ccw according to its rainbow color if blob remains contiguous and there is no collision.
* 6 rotate blob clockwise.
* Y rotate blob ccw.
* LEFT/RIGHT ARROW translate the blob left or right.
* DOWN ARROW drop the blob slowly.
* UP ARROW drop the blob immediately.
* SPACE capitalize completed rows.
